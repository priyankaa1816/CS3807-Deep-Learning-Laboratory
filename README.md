![Python](https://img.shields.io/badge/Python-3.10+-3776AB?logo=python&logoColor=white)

A collection of laboratory experiments, Python implementations, reports, and supporting resources completed as part of the **CS3807 – Deep Learning Laboratory** course at **Shiv Nadar University Chennai**.

The repository covers fundamental concepts in deep learning, beginning with the implementation of a **Single Layer Perceptron (SLP)** and progressing to **Multi-Layer Perceptron (MLP)** models for image classification and neural network optimization.
